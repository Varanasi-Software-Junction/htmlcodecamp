Responsive Images in HTML

Load different images for Mobile (600px), Tablet (1024px), and Desktop — the correct way.

Why Responsive Images?

A mobile user should not download a heavy desktop image. Responsive images ensure:

  • Faster loading
  • Less data usage
  • Better SEO & performance

Method 1: <picture> (Best Method)

This gives you full control over which image loads on which screen. 

<picture>
  <!-- Mobile (up to 600px) -->
  <source media="(max-width: 600px)" srcset="https://programmer-s-picnic.github.io/json-images/mobile.png">

  <!-- Tablet (up to 1024px) -->
  <source media="(max-width: 1024px)" srcset="https://programmer-s-picnic.github.io/json-images/tablet.png">

  <!-- Desktop -->
  <source media="(min-width: 1025px)" srcset="https://programmer-s-picnic.github.io/json-images/desktop.png">

  <img src="https://programmer-s-picnic.github.io/json-images/desktop.png" alt="Responsive Image" loading="lazy">
</picture>
✔ Loads only one image
✔ Perfect for comics, banners, illustrations
